# Style Guide and Conventions

Follow language conventions to keep code readable and maintainable.

## Go

- gofmt is mandatory.
- Errors are values: return early.
- Prefer small packages and explicit interfaces.

## PHP

- PSR-12 as a default.
- One class per file, clear namespaces.
- Use strict typing where possible.

## Python

- PEP 8 formatting.
- Use type hints for public APIs.
- Keep modules small and cohesive.

## Node.js

- Prefer async/await over callbacks.
- Use eslint + prettier.
- Keep layers separated: routes, services, data.
