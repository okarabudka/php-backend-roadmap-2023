# Performance Profiling

Measure first, optimize second. Learn the profiling tools per language.

## Go

- `pprof` CPU and heap profiles.
- `trace` for goroutine and scheduler analysis.
- Benchmarks with `testing.B`.

## PHP

- Xdebug profiler for local runs.
- Blackfire for production profiling.
- OPcache status for runtime insights.

## Python

- cProfile for CPU.
- py-spy for sampling without overhead.
- line_profiler for hotspots.

## Node.js

- Node inspector CPU profiles.
- clinic.js for performance diagnosis.
- `--trace-gc` for GC analysis.
