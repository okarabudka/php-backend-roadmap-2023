# Ecosystem and Tooling

Understand the core tools around your language. Pick defaults and stick to them.

## Package management

- Go: `go mod` for modules and versioning.
- PHP: Composer for dependencies and autoloading.
- Python: pip + venv/poetry.
- Node.js: npm/yarn/pnpm.

## Formatting and linting

- Go: `gofmt`, `golangci-lint`.
- PHP: PHP CS Fixer, PHP_CodeSniffer.
- Python: black, ruff, flake8.
- Node.js: prettier, eslint.

## Debugging and profiling

- Go: `delve`, `pprof`.
- PHP: Xdebug, Blackfire.
- Python: pdb, py-spy.
- Node.js: Node inspector, clinic.js.

## Build and task runners

- Go: `go build`, `go test`.
- PHP: Composer scripts, Makefile.
- Python: `make`/poetry scripts.
- Node.js: npm scripts, task runners.

## IDE setup

- Use language server support.
- Enable auto-format on save.
- Add common snippets and file templates.
