# Language Fundamentals Checklist

Minimum topics to be productive in any language. Use this as a progress checklist.

## Core syntax

- Variables and types
- Control flow (if/else, loops)
- Functions and modules
- Error handling
- I/O and files

## Data structures

- Arrays/lists
- Hash maps/dictionaries
- Sets
- Stacks/queues
- Custom structs/classes

## OOP and design basics

- Encapsulation, inheritance, composition
- Interfaces and polymorphism
- Dependency injection basics
- Simple design patterns (factory, strategy)

## Runtime and memory

- Value vs reference semantics
- Heap vs stack
- Garbage collection or refcounting
- Common memory pitfalls

## Concurrency and async

- Threads or coroutines
- Async I/O
- Synchronization primitives
- Common race conditions

## Networking and web

- HTTP fundamentals
- Client/server basics
- JSON serialization
- Authentication basics

## Tooling

- Package manager
- Formatter and linter
- Debugger basics
- Build/test commands

## Testing

- Unit tests
- Integration tests
- Mocks/stubs

## Production readiness

- Logging and metrics
- Configuration management
- Environment handling
- Basic security practices
