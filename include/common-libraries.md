# Common Libraries

Minimal library sets to build typical web services.

## Go

- HTTP: chi or gin
- Config: viper
- Logging: zap or zerolog
- DB: sqlx or gorm
- Migrations: goose or migrate

## PHP

- HTTP: Symfony HttpFoundation
- Config: vlucas/phpdotenv
- Logging: monolog
- DB: doctrine/dbal or eloquent
- Migrations: phinx or Laravel migrations

## Python

- HTTP: requests or httpx
- Config: pydantic-settings
- Logging: structlog
- DB: SQLAlchemy
- Migrations: alembic

## Node.js

- HTTP: express or fastify
- Config: dotenv
- Logging: pino
- DB: prisma or knex
- Migrations: prisma migrate
