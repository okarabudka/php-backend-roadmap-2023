# Language Choice Matrix

Use this matrix to pick a primary backend language for the next 6-12 months.

## Quick decision rules

- Choose Go if you need performance, concurrency, and simple deployment.
- Choose PHP if you target web products with fast iteration and huge hosting availability.
- Choose Python if you need data tooling or rapid prototyping.
- Choose JavaScript/Node.js if you want one language across frontend and backend.

## Evaluation criteria

Score each language 1-5 and compare totals:

- Team availability and hiring market
- Library maturity for your domain
- Performance and latency needs
- Concurrency model fit
- Ops and deployment simplicity
- Long-term maintainability
- Ecosystem tooling (linters, formatters, profiling)
- Personal motivation and community fit

## Typical use cases

- Go: APIs, microservices, high-load systems, CLI tools.
- PHP: web apps, CMS/commerce, internal tools, APIs with Laravel/Symfony.
- Python: data services, automation, ML/ETL, fast prototypes.
- Node.js: realtime apps, BFFs, fullstack JS.

## Decision output

Pick one primary language and one secondary language for the year. Commit to it for at least one full project.
